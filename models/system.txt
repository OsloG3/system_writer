# ============================================================================
# The bidding bot's system -- a 2/1 Game Force system, in one text file.
#
# This file is the single source of truth for the system the bots are trained
# to follow and for the bid alerts the website shows:
#
#   * bidding-dt interprets it at the START OF TRAINING (rl/train_ppo.py
#     --system / rl.system_file / BIDDING_SYSTEM_FILE, default search:
#     models/system.txt then ../models/system.txt): the config lines tune the
#     checker thresholds and every pattern entry becomes a per-call check
#     (conventions/patterns.SystemEnforcer, wired through rl/rollout.py).
#     The file is a PURE CONSTRAINT on the policy: matching entries only ever
#     PENALIZE infringements (hand description, F/GF/TO/PENALTY discipline);
#     there is no positive convention shaping and no rule-based bidder that
#     generates auctions from the file anymore.
#   * the website (system_writer) reads the same file and GENERATES THE BID
#     ALERTS from it (patterns.go + auction.go, ports of the Python engine).
#
# Every entry carries the hand requirements its call promises, so a violation
# is a call whose hand does not match what the system says the call shows.
# Strength is in Kaplan-Rubens points (kr.py); every range carries
# +-kr_tolerance slack.
#
# FORMAT
#
# Config lines (bare identifier = value; ranges "lo-hi", booleans yes/no):
#     kr_tolerance = 1.0        slack applied to every p-token range
#     to_pass_min_len = 3       trumps in their suit to pass a TO double
#     ...                       (any ConventionConfig field or SPEC_PARAMS key)
#
# Pattern entries -- one line each, checked in FILE ORDER, first match wins
# (put specific entries before general ones):
#     PATTERN[; CLAUSES] = DESCRIPTION [@weight] [@!]
#
# PATTERN    calls joined by "-", matched from the dealer. Steps: literal calls
#            (1H, 2NT, P, X/DBL, XX/RDBL), generic suits 1X/?Z (X Y Z W bind
#            pairwise-distinct suits, a repeated letter the same suit), negated
#            !2D, opponent calls in parentheses (1Y), and "..." absorbing any
#            run of calls. Leading passes are skipped; opponent passes between
#            our steps are skipped implicitly (own passes must be written out).
#            The LAST step is the call being described.
#
# CLAUSES    after ";" (or ":"), OR-combined groups of AND atoms: suit
#            comparisons X<Z / T=P over pattern vars, literals and context suits
#            T (our last suit) P (partner's) L (theirs) O (other major); candidate
#            shape jump=0 / level>=3 / below=4H; state gf, uncontested, contested,
#            balancing, passed, first, opener, partnerbid, newsuit, we_bid,
#            notopening, noxyz, nostrong2c, fourth, we_xx, they_xx,
#            dbls_by_us>=N, bids_by_them=0, their_bid>=4S, our_bid>=1C. Any may
#            be negated with "!".
#
# DESCRIPTION  the alert text AND the training spec. " OR " splits multiway
#            alternatives (the hand must satisfy ALL checkable tokens of ANY
#            branch; a branch with no checkable token is a wildcard). Enforced
#            tokens: lengths 5+X / 4-6H / 6X / 8+any / 0-1Y; points p>16 /
#            p15-17 / p<10 / p>=12; balanced; openp (opening values incl. rule of
#            20, lighter in 3rd/4th seat); no4M / noMajor / noLong5M; stop /
#            !stop (stopper in their suit); 2top; RKCB kc=0/3 / kc=1/4 / kc=2- /
#            kc=2+. A token may be negated with "!" (!stop = no stopper,
#            !balanced = unbalanced). Entry keywords: F (one-round force:
#            bid-(pass)-pass charges the PARTNER's pass), GF (game force:
#            judged on the COMPLETED auction -- the GF side's LAST pass is
#            charged when it declares an undoubled partscore or defends an
#            undoubled contract), and for doubles TO / PENALTY (these
#            describe the PARTNER's discipline, not the doubler's hand).
#            {X}/{T}/{P}/{L}/{O} render as suit symbols; everything else is
#            free alert text.
#
# @weight    penalty weight (default 1.0; @0 = alert-only). A matched entry with
#            weight>0 REPLACES the built-in rule checks for that call.
# @!         artificial (the website shows the alert marker).
#
# Calls no entry matches fall back to the built-in rule checks during training
# and show no alert on the site. Ship this file next to the checkpoint it
# describes; the Go server re-reads it whenever it changes on disk.
# ============================================================================
