# ============================================================================
# The bidding bot's system -- conventions in one text file.
#
# This file is the single source of truth for the system the bots are trained
# to follow and for the bid alerts the website shows:
#
#   * bidding-dt interprets it at the START OF TRAINING (rl/train_ppo.py
#     --system / rl.system_file, default search: models/system.txt then
#     ../models/system.txt): every `weight` becomes a convention-penalty rule
#     weight and every numeric key a ConventionConfig threshold, so editing a
#     range here re-tunes what the RL loop enforces (rl.conv_weight).
#   * the website (system_writer) reads the same file and GENERATES THE BID
#     ALERTS from it: the Go server classifies the live auction against the
#     system and serves the matching section's `alert` text for every bot
#     call (and for each of the human's legal options). No self-play
#     statistics are involved.
#
# Format (INI-like):
#   [section]                 one section per call kind; section names are the
#                             convention rule codes (bidding_dt.conventions.
#                             rules.DEFAULT_WEIGHTS) plus a few alert-only
#                             kinds (rkcb_ask, resp_2c_waiting,
#                             balancing_takeout, penalty_double)
#   alert = text              what the website shows for a call of this kind;
#                             placeholders: {call} {suit} {other} {trump}
#                             {partner_suit} {shows} {level}
#   artificial = yes          mark the call with the alert (⚠) symbol on the
#                             website (default: no)
#   weight = N                convention-penalty weight used by training
#                             (0 disables the rule; only valid on rule codes)
#   steps = a | b | c | d     RKCB step-response texts ({shows} placeholder)
#   <param> = value           numeric threshold interpreted by training
#                             (ConventionConfig field names; ranges "lo-hi",
#                             booleans yes/no)
#   # comment                 lines starting with # or ; are ignored
#
# Strength numbers are Kaplan-Rubens points (conventions/kr.py), applied with
# +-kr_tolerance slack. Ship this file to the server next to the checkpoint it
# describes (models/system.txt); SYSTEM_FILE overrides the path.
# ============================================================================
